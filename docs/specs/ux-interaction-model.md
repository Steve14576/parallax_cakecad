> 适用范围：曲奇纵切及之后的所有交互实现

## 1. 最高原则：谓语与宾语分离

命令是一个谓语加一组宾语，谓语独立注册，宾语在执行时由用户选择。

```text
正确：倒入(面粉 → 搅拌碗)
错误：菜单项“倒入搅拌碗”——谓语和宾语被绑死
```

推论：

- 菜单里不出现固定宾语的命令项；
- 宾语通过点选、多选、框选或参数输入获得；
- 同一谓语可以从右键、工具栏、CMD 三个入口发起；
- 三个入口共享同一份命令注册表，不各写一份逻辑。

每个命令必须声明它的宾语签名，例如：

```text
倒入(material → container)
放入(object → container | region)
分件(material | intermediate → N 份)
开始操作(operation_type × participants...)
```

## 2. 选择模式状态机

任何时候界面处于以下状态之一：

```text
idle（空闲）
→ selected（已选中对象）
→ armed（命令已激活，等待点选宾语）
→ picking（点选进行中，显示还差几个什么角色的宾语）
→ preview（参数齐备，显示将发生什么）
→ commit（Enter/确认，写入事实底座）
```

规则：

- Esc 逐级退出：preview → picking → armed → idle；
- armed/picking 状态下，状态栏显示命令名与所需宾语角色；
- 先选后动词（SW 式）与先动词后选（AutoCAD/Rhino 式）都合法，落到同一状态机；
- Ctrl+点击 多选；工作区支持框选；多选结果可被谓语直接消费。

## 3. 三个命令入口的分工

### 3.1 右键菜单

右键菜单项全部是谓语，分两层：

- 通用区：对所有对象可用（命名、放入、创建分支、打书签、撤下热区）；
- 角色区：按对象角色追加（物料：倒入/称量/分件；设备：启动其过程；容器：清空/标记清洗）。

选择谓语后进入 picking 状态，由用户点选宾语。菜单本身永远不列“倒入搅拌碗”这类组合项。

### 3.2 工具栏

放高频谓语。点击工具进入 armed 状态，连续点选宾语，Enter 提交。适合手不离鼠标的操作。

### 3.3 CMD

输入谓语进入 picking 状态，支持参数内联输入（如 `分件 6`）。适合手不离键盘的操作。

## 4. DAW 解剖

DAW 由以下部件构成，缺一不可（首纵切范围内）：

### 4.1 标尺与 playhead

- 顶部时间标尺；
- 一条竖直当前时刻指针（playhead），带顶部手柄；
- 拖动 playhead 移动当前时刻；新片段默认从 playhead 处开始；
- playhead 吸附到片段首尾边界；
- playhead 是注意力锚点，不阻止编辑过去或未来。

### 4.2 片段（clip）

- 一切操作默认有长度；未给定时长时生成默认短片段（候选默认 5 秒级刻度）；
- 拖片段中部移动整体；拖左右边缘改变首尾；
- 结束未知：右边缘虚线/渐变；时间未知：斜纹；
- 点事件只留给真正瞬时的记录（测量、观察、命名）；为保证可选中，渲染时有最小宽度，但语义上仍是点。

### 4.3 热区与冷区

- 冷热区选项卡贴在 DAW 头部轨道控制区，不属于工作区；
- 热区：被搬出来操作、正在变化或选中的片段，允许汇聚、转化、分叉；
- 冷区：所选时段内仍存在的对象与关系，以细横线流过，弱强调，用于回答“这个时段还有什么”；
- 操作结束可从热区撤下，对象仍在冷区与历史中；
- 冷热区不控制工作区对象的可见性。

### 4.4 分支泳道

分支以平行泳道呈现，显示共同祖先、分叉点和各自片段。首纵切只要求显示主线与一条分支。

## 5. 空间提交

- 工作区拖拽只产生 sketch 级位置记录，不弹窗、不打断；
- 提升为 declared/committed 必须通过谓语命令（放入、倒入等）；
- 空间关系进入物料事实永远需要用户确认，确认动作就是执行谓语，不是审批拖拽。

## 6. 曲奇纵切初始命令词汇表

以下为候选词汇表，用于首纵切实现，可在体验后增删，但增删必须先改本节。

| 谓语 | 宾语签名 | 结果 |
| --- | --- | --- |
| 新建对象 | （名称，角色） | 新 Object，落在 playhead |
| 命名 | object × 名称 | 命名事件 |
| 放入 | object → container/region | 位置关系（sketch→declared） |
| 倒入 | material → container | 物料转移事件（committed） |
| 取出 | material ← container | 位置关系结束 |
| 分件 | material/intermediate → N | 子对象 + 来源关系 |
| 开始操作 | 类型 × 参与者 | 持续片段，落在 playhead |
| 结束操作 | 进行中的片段 | 关闭片段右端 |
| 记录测量 | object × 量 × 值 | Measurement + Lock |
| 快速估算 | 片段/对象 | 先验建议结果卡 |
| 回填实测 | 片段 × 值 | 实测事件，分析过期 |
| 创建分支 | 时刻 × 名称 | 分支泳道 |
| 撤下热区 | 片段/对象 | 冷区呈现 |

## 7. 曲奇 Demo 的里程碑门

不允许继续零碎散改。Demo 按里程碑推进，每个里程碑跑通后先体验、回写文档，再进入下一个。

### M1 交互内核（当前目标）

验收：

1. playhead 可拖动，新片段落在 playhead；
2. clip 可整体拖动、可拖首尾改变长度；
3. 右键菜单全部是谓语，无任何固定宾语项；
4. 从右键选择“倒入”后进入点选容器状态，Enter 提交；
5. CMD 输入“倒入”走同一状态机，同样完成；
6. 一次完整链路：拖面粉（sketch）→ 右键倒入 → 点碗 → Enter → DAW 出现有长度的 committed 片段；
7. 冷热区选项卡位于 DAW 头部，切换不影响工作区。

M1 体验确认后，回写本文件与纵切规格，再进 M2。

### M2 曲奇业务闭环

命名“曲奇面团” → 分件产生子对象 → 入炉烘烤保持同一 ID → 回填实测时间与质量 → 从混合处创建黄油软化版分支并比较。

### M3 分析与传记

先验建议、过程观察窗口、后验检查、对象传记来源回溯。
