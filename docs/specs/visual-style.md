# CakeCAD 视觉语言规范

> 文档状态：正式下游规格初稿  
> 上游约束：`docs/MASTER_SPEC.md`、`docs/specs/ux-interaction-model.md`  
> 风格来源：`file_researches/coffeehour_chat_refs/chat6_单点补充_UI风格参考.md`  
> 适用范围：全部界面实现

## 1. 采用范围声明

chat6 提供的 MODEL/SCULPT/DECORATE/RENDER/ANIMATE/EXPORT 六模式结构、3D 视口永久居中、"从模型自动生成 Markdown / 从文档反向改模型"等设计**不采用**，它们与 MASTER_SPEC 的懒几何、Markdown 不自动执行、DAW 一级主轨冲突。

采用其视觉语言，并与已拍板的便签代理物体系融合：

> **外壳是深色工程实验室，对象是有温度的纸质便签。**  
> 参数像工程数据，对象像侦探板上的证物。

一句话风格定位（改写自 chat6）：

> CakeCAD 是一间暗色数字过程实验室：轨道与参数是精密仪器，对象像钉在侦探板上的便签，琥珀色只点亮当前正在被操作的东西。

## 2. 色彩系统

### 2.1 深色外壳

| 用途 | 色值 |
|---|---|
| 全局背景 | `#080909` |
| 视口/画布底色 | `#0D0E0E` |
| 面板背景 | `#111211` |
| 浮层背景 | `#171817` |
| 分割线 | `#292522` |
| 弱边框 | `#3A3029` |

### 2.2 强调色（克制使用）

| 用途 | 色值 |
|---|---|
| 主琥珀（选中、当前模式、关键操作） | `#C66B2C` |
| 高亮橙（hover、playhead、关键帧） | `#F08A3C` |
| 暗铜（时间轨辅助、弱强调边框） | `#704022` |
| 金（成功提示） | `#D99A42` |
| 深红（警告、错误、冲突） | `#A34232` |
| 冷灰（次级信息、禁用） | `#747574` |

强调色只用于：当前选中、活跃命令状态、playhead、关键按钮、可交互边界。不大面积铺设。

### 2.3 对象便签色

对象代理物保持纸质便签质感，在深色画布上自然凸显。身份色仍遵守 MASTER_SPEC 16.7：文字标题为主，横杠/色条仅辅助，用户自定义颜色只是样式。

## 3. 字体与文案

- 界面与数值：等宽/窄体无衬线（JetBrains Mono、IBM Plex Mono）；
- 中文：Noto Sans SC / 思源黑体；
- 文案短、工程化、低情绪，以名词和动词为主；
- 状态文案采用 `STATUS: READY` 式仪表语言；
- 禁止营销式文案（"一键打造专属甜点"类）。

## 4. 形体语言

- 细边框与留白分隔优先，少用厚重卡片阴影；
- 面板圆角 2–6px，输入框 2px，弹窗 6px，按钮 2–4px；
- 阴影低扩散低透明：`0 8px 24px rgba(0,0,0,.42)`；
- 光效只表达状态（选中轮廓、playhead、录制/错误点），不做装饰；
- 图标细线单色，hover 橙边，active 橙色+低透明底。

## 5. 状态反馈语言

| 状态 | 表现 |
|---|---|
| 选中对象 | 琥珀描边 + 面板同步 |
| armed/picking 命令状态 | 状态栏显示命令名与待选宾语角色，光标变化 |
| 参数已修改 | 数值短暂变橙 |
| 成功 | 状态栏金色短文案（`SAVED`、`COMMITTED`） |
| 错误 | 深红文案，说明原因与建议动作 |
| 分析派生标记 | 独立徽标，不与用户颜色混淆 |

## 6. 布局骨架与工作面映射

主界面布局骨架已定（参考 chat6 原图，用户拍板“改”），映射到 CakeCAD 工作面：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：Logo/项目/分支 · 一级主轨选项卡 · 本地状态/时钟/系统状态    │
├──────────────────────────────────────────────────────────────┤
│ 视口条：网格/对象数/选中对象/HUD 信息                            │
├───┬──────────────────────────────────┬───────────────────────┤
│ 工 │ 中央：语义代理工作区（深色台面+便签） │ CAKE MARKDOWN         │
│ 具 │                                  ├───────────────────────┤
│ 栏 │                                  │ INSPECTOR 对象传记      │
│    │                                  ├───────────────────────┤
│    │                                  │ CAKE CMD 终端（历史）   │
├───┴──────────────────────────────────┴───────────────────────┤
│ CAKE DAW：走带控制/时间码 · 轨道头 + 片段 + playhead · 冷热区选项卡│
├──────────────────────────────────────────────────────────────┤
│ 状态栏：STATUS: READY · 命令进行态 · CAKECAD                   │
└──────────────────────────────────────────────────────────────┘
```

要点：

- 顶栏中央选项卡用于切换两条一级主轨（物料＆操作 / 物料＆位置），不是 chat6 的六模式；
- 左侧竖排工具栏放高频谓语工具；
- Markdown 位于右上，CMD 为右下带历史的终端面板（提示符、命令历史、OK/错误回显）；
- DAW 含走带控制、时间码、左侧轨道头（每条事件/对象一轨）、片段与 playhead；
- Inspector 采用 STATS 式小字号数据行 + 传记文本。
